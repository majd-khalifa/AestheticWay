# Patient branded-placeholder baselines

The user explicitly requested retained media geometry for missing photographs. This family replaces the former compact clinic-gallery fallback with the same 16:9 hero frame and a neutral AESTHETIC WAY panel. All older baseline families remain unchanged.

Native Linux and Windows own separate exact pixel baselines. Shared geometry/style assertions retain 1/16dp precision. No tolerance, skips, timeout changes or fixture photographs standing in for missing media. Native Windows candidates must be obtained through the existing CI capture step, visually reviewed and checked against Linux geometry before adoption. Provenance records that review; pre-adoption missing Windows baseline failures are not production verification.
